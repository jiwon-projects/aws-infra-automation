# Day 13 — GHCR 게시 이미지 실행 검증 자동화

- 이미지 게시 워크플로에 배포용 Compose 실행 검증을 추가했다.
- 방금 게시한 이미지의 Digest를 다음 단계에 전달했다.
- GHCR 이미지를 내려받고 로컬 재빌드 없이 실행했다.
- API에서 alive, ready, release-ci 응답을 검사했다.
- 실행 컨테이너의 이미지 참조가 지정한 Digest와 같은지 확인했다.
- Nginx와 FastAPI 간 내부 통신 및 8000번 포트 미게시를 검사했다.
- 검증 후 컨테이너와 네트워크가 제거된 것을 확인했다.
- Summary에 실행 검증 성공 결과를 기록했다.

## 검증 범위

- AMD64·ARM64 이미지 빌드 및 게시
- 이번 실행 검증은 GitHub Linux AMD64 환경 대상
- AWS 리소스나 개인 GitHub 토큰은 사용하지 않음

## 현재 자동화 흐름

PR → 필수 CI 통과 → main 병합 → main CI 성공
→ 이미지 게시 → Digest 기반 실행 검증 → 컨테이너 정리

검증은 게시 후 수행하므로, 실패한 이미지가 자동 삭제되는 것은 아니다.
배포에는 게시 워크플로가 최종 성공한 Digest를 사용한다.
