# Day 17 — 잘못된 이미지 Digest 감지 자동 검증

## 변경 내용
- 이미지 게시 워크플로에 잘못된 Digest를 전달하는 검사를 추가했다.
- 종료 코드가 1인지, 이미지 불일치 오류 문구가 있는지 함께 확인한다.
- 실패 감지 검사 이후 기존 정상 배포 검증을 실행한다.

## 검증 결과
- 잘못된 Digest를 전달했을 때 이미지 불일치를 감지했다.
- 예상한 실패를 확인한 단계는 성공으로 처리됐다.
- 올바른 Digest를 사용하는 후속 검사 6개가 모두 통과했다.
- 컨테이너 정리 단계와 전체 게시 작업이 성공했다.

## 배운 점
- 검증 도구는 정상 상태의 성공과 잘못된 상태의 실패를 모두 확인해야 한다.
- 종료 코드뿐 아니라 오류 원인도 확인해야 다른 실패를 오인하지 않는다.
- 기대값만 임시로 변경했으며 실행 중인 컨테이너는 교체하지 않았다.
- AWS 리소스는 생성하지 않았다.
