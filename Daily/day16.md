# Day 16 — 배포 검증 스크립트를 GitHub Actions에 연결

## 변경 내용
- 이미지 게시 워크플로의 개별 검사 세 단계를 공통 검증 스크립트 호출로 교체했다.
- PR의 Docker 통합 검사 작업에 스크립트 문법 검사를 추가했다.
- 기존 로그 출력과 컨테이너 정리 단계를 유지했다.

## 검증 결과
- PR의 필수 검사 3개를 통과했다.
- 병합 후 이미지 게시 워크플로가 성공했다.
- GitHub Actions에서 배포 검증 스크립트의 6개 검사가 모두 통과했다.

## 배운 점
- 로컬과 자동화 환경에서 같은 검증 스크립트를 사용할 수 있다.
- Compose 프로젝트 이름과 환경 변수로 검사 대상을 구분한다.
- PR에서는 문법을 검사하고, 이미지 게시 후에는 실제 실행 상태를 검사한다.
- 이미지 빌드는 AMD64·ARM64 대상이며, 이번 자동 실행 검증은 AMD64 환경에서 수행했다.
- AWS 리소스는 생성하지 않았다.
