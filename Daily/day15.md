# Day 15 — 배포 검증 스크립트 작성

## 구현 내용
- scripts/verify_release.sh에 배포 상태 검사를 묶었다.
- 인자로 Compose 프로젝트 이름을 받아 검사 대상을 선택한다.
- 검사 실패 시 0이 아닌 종료 코드로 종료한다.

## 검사 항목
- API와 Nginx 컨테이너 실행 여부
- 기대하는 이미지 Digest와 실행 이미지 참조 일치 여부
- API 컨테이너 헬스체크 상태
- Nginx를 통한 alive, ready 응답
- 실행 환경과 버전 일치 여부
- Nginx에서 API로 내부 통신
- API 8000번 포트의 호스트 미게시 여부

## 실습 결과
- 정상 상태에서 전체 검사 통과를 확인했다.
- 잘못된 Digest를 전달했을 때 이미지 불일치를 감지했다.

## 배운 점
- 실행 상태와 기대값을 비교해 배포 결과를 확인할 수 있다.
- 검증 스크립트는 컨테이너를 변경하지 않고 현재 상태를 검사한다.
- 명령 앞의 임시 환경 변수는 해당 명령에만 적용된다.
- AWS 리소스는 생성하지 않았다.
