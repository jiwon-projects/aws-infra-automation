# Day 14 — Digest 기반 이미지 교체와 롤백

## 실습 내용
- Mac ARM64 환경에서 이전 이미지와 새 이미지를 준비했다.
- 배포용 Compose로 이전 이미지를 실행했다.
- 새 이미지의 Digest를 지정하여 컨테이너를 교체했다.
- 이전 Digest를 다시 지정하여 수동 롤백했다.

## 검증 결과
- 각 단계에서 실행 컨테이너의 이미지 참조가 지정한 Digest와 일치했다.
- 교체 및 롤백 후 alive, ready 응답을 확인했다.
- 환경값 rollback-test와 버전 0.1.0을 확인했다.

## 배운 점
- 이전 이미지를 보관하면 재빌드 없이 해당 이미지로 복구할 수 있다.
- API 응답이 같아도 이미지 참조를 비교하면 교체 여부를 확인할 수 있다.
- API와 Nginx를 함께 다시 생성했으며, 교체 중 잠시 서비스가 끊길 수 있다.
- 실제 장애 대신 정상 이미지 두 개로 수동 롤백 절차를 연습했다.
- AWS 리소스는 생성하지 않았다.
